# Socials — visuels Instagram ARWEB

Images publiées via GitHub Pages pour être programmées dans Metricool.

- `content/` : textes des posts (slides, légendes, hashtags, dates) par mois.
- `YYYY-MM/<id>-<slug>/<n>.png` : visuels 1080 × 1350 px, un fichier par slide.
- `tools/render.py` : génère les PNG à partir d'un fichier de contenu (`python3 tools/render.py content/mois-1.json`).

URL publique : `https://arweb-ma.github.io/Socials/<chemin>`

Ne jamais déposer ici de données clients : le dépôt est public.
